# Outside-store hypothesis: rejected in development

This is a separate, uncalibrated version of the economy. It adds competing non-PayPal purchases with real debits/refunds to simulated shopper wallets; it is not a result on the previous frozen simulator. The original benchmark source is unchanged.

The new engine passes closed-mode row parity against the original engine, monetary conservation, observation privacy, and a zero-response placebo in which outreach cannot generate commerce. Outside purchases remain evaluator-only and never enter agent observations.

All four active policies lost modeled platform contribution on the 15 development markets. The release selection was **organic**. We did not spend on agent approvals, open the planned confirmation set, or promote this environment as evidence of a profitable intervention. The explicit assumptions, code hashes, proposed splits and complete failed development outcomes are preserved in `protocol.json` and `development.json`.

The later focused-recovery experiment returns to the original closed-market behavioral and financial equations. Its outcome must not be attributed to the outside-store model.
