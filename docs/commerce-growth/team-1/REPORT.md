## What was improved

A pooled response prior was fitted from2,499 observed development contacts and their matured outcomes. Cold inquiries no longer inherit an expensive old purchase as their assumed new basket. A separate numerical tool compares Poisson demand forecasts using past-only temporal validation. Joint basket allocation and bounded replenishment are available to agents and strong fixed controls alike.

The outreach scientist chooses targeting and contact controls; the fulfillment engineer chooses the forecasting and inventory program; the coordinator resolves their proposals. On day60 the coordinator revisits the contract using that market's observed results. A matched single planner receives the same model, four calls, tools, data and action space. No development subagents were used.

## Interpretation limits

- Seven unseen markets, one seed per regime. This is a bounded pilot, not a precise population estimate.
- All buyer behavior, funding, consent and response rules stayed frozen. Strong fixed rules received the same joint fulfillment tools.
- This is an offline step-based benchmark. Provider latency is measured separately; it does not advance the market clock.
- Agent contracts are chosen by fresh Gemini calls on days30 and60. Trusted local code handles per-customer ranking, forecasting, stock, funds and execution.
- Recorded cost uses metered tokens and configured list prices, including thinking tokens; it is not a billing invoice. The pilot cost is conservatively charged once to each LLM arm in comparative scores, while actual total spending counts it only once.
- All economic values are authored simulation estimates, not real PayPal profit. No native payment was made.

The checkpoint files preserve the actual role inputs, concise decision rationales, validated contracts and provider usage. Earlier negative results and the original simulation remain intact. These test seeds are now spent and cannot be reused as unseen evidence after further tuning.
