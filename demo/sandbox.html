Connect your PayPal sandbox app
  1. Open PayPal Developer Dashboard. In Apps & Credentials, select Sandbox and create an app named Supply Yard.
  2. Copy .env.example to .env in this project. Set PAYPAL_CLIENT_ID and PAYPAL_CLIENT_SECRET using that sandbox app. Keep the secret in this local file.
  3. Restart npm run dev, reload this page, and test the connection.
  4. For buyer approval, use a Personal sandbox account from the dashboard’s testing tools. It must be different from the app’s Business sandbox account.

The secret and OAuth token stay on the local server. The payment API host is fixed to api-m.sandbox.paypal.com.
